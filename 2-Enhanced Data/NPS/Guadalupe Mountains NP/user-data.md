## Key Activities

- [ ] Guadalupe Peak Trail (6-8 hours) - Highest point in Texas
- [ ] McKittrick Canyon Trail to Pratt Cabin (2.5-3 hours) - Fall colors
- [ ] Devil's Hall Trail (3-5 hours) - Natural limestone staircase
- [ ] Smith Spring Trail Loop (1-2 hours) - Two desert springs
- [ ] El Capitan Trail (4-5 hours) - Base of iconic peak
- [ ] Salt Basin Dunes Trail (1-3 hours) - Gypsum sand dunes
- [ ] Pinery Trail (30 minutes) - Historic Butterfield station
- [ ] Frijole Ranch Cultural Museum (30-60 minutes) - 1876 ranch
- [ ] Night Sky Stargazing (1-2 hours) - Bortle class 2 dark skies
- [ ] El Capitan Viewpoint (5-15 minutes) - Roadside views
